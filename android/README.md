# Спасаем маму-птицу — Native Android 3.0

Полностью нативное Android-приложение на Kotlin + Jetpack Compose.

- без WebView;
- API: https://mellstroy.work.gd/api/v1/;
- лента в стиле Reddit/X;
- нативные посты, фото, лайки, ответы и просмотры;
- отдельный нативный экран статуса;
- отдельный чат @mellai;
- вход/регистрация и CAPTCHA;
- нативная тревожная индикация и звук;
- профиль пользователя.

Ветка: android-native
