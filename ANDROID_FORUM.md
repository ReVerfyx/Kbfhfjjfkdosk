# Android Forum

Ветка `android-forum` содержит отдельное Android-приложение форума.

- При первом запуске приложение спрашивает домен/IP сайта.
- После сохранения открывает `/forum`.
- Сохраняет cookies входа.
- Поддерживает загрузку изображений из системного файлового выбора.
- Кнопка ⚙ позволяет сменить сервер.
- GitHub Actions собирает debug APK и публикует его как artifact.

После привязки домена можно ввести, например:

`https://example.com`

Приложение само откроет `https://example.com/forum`.
