# Спасаем маму-птицу — Android

Полная Android-версия сайта, привязанная к:

https://mellstroy.work.gd

В приложении есть:
- Главная
- Статус
- Форум
- @mellai
- авторизация и cookies
- публикация фотографий
- тревожный режим сайта со звуком и красной индикацией
- открытие внешних источников в браузере

Адрес сервера вводить не нужно: домен уже встроен.

Сборка APK выполняется автоматически в GitHub Actions из ветки `android-forum`.
